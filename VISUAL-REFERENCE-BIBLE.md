# Visual reference rules — supplied by the user

The descriptions supplied on 2026-10-07 are the production reference. The source PV files are not dependencies and no official frames, models, UI or extracted resources enter this project. Study the grammar and create original forms.

Impact comes from contrast between states, not object count. A shared motif mutates: a shell becomes its fracture, an aperture, a partial curve, an orbit, a shadow or an internal core. Repeating a complete model is not the motif system.

Every independent anchor has a physical idea and ten explicit fields in `src/data/shots.json`: visualCategory, dominantPalette, materialIdentity, lightingIdentity, atmosphere, scaleRange, foregroundType, cameraBehavior, shotEvent, exitTransition. Continuing pieces of the same anchor are labelled as continuations. Declared differences do not substitute for visual review.

The independent modes include ink/paper invading a sphere; enclosed blue-black mechanical mass; hard white architectural shadow; counterflowing cyan data; crimson lighting; violet organic membrane; a physically refractive threshold; a mirror with independent gravity; amber fractured instruments; black-green laser depth; clipped white/cyan/pink light flow; torn print; corrupted monitor signal; an enclosed blue-black water/glass gallery whose exit opens, and clean sky afterglow.

Use deep black areas, overexposed areas, rim light, transparent overlap and atmosphere as composition. A colour world changes the light, air and shadow as well as the object. Dense and empty shots have different purposes. The quiet end is a sustained emotional release, not a new spectacle every few seconds.

Every 8–12 seconds in the active sections should change at least four of palette, material, lighting, camera, visual medium and atmosphere. Every 2–4 seconds needs a perceptible event. The intentional opening restraint and final afterglow provide growth and release.

The user prefers the immersive fibre/aperture approach: foreground fills the edges, depth is explicit, and the destination has strong negative space. Other 3D worlds need comparable intrusion, not an isolated object in an empty room.

The five original combined Blender candidates are documented in `BLENDER-SHOT-DESIGNS.md`. Rejected material tests live in `research/material-tech` as R&D ONLY. Candidates are first rendered as independent event sequences in GitHub Actions. They enter the film after composition, event and transition checks, not because a shader compiled.

Formal Blender sequences, section movies, opening review, full preview, final export, contact sheets and MP4 checks are GitHub Actions only. Local development uses individual stills and necessary short debugging. Camera/world dynamics are seeded absolute poses. Source audio stays private current-tree input; existing history is retained under the user's explicit decision.

The whiteout is a real clipped light-flow state, not giant text on a pale background. Ink geometry is intentionally cropped at macro distance. A luminous dawn breach puts the hanging living relic in silhouette; it is not evenly grey-lit.

Physical sequence review uses Cycles CPU at 960×540, 30fps, 8 samples plus denoising; final assets use 1920×1080, 30fps, 16 samples plus denoising. Four absolute frame ranges per shot render independently in Actions. Assembly rejects gaps, duplicates, dimension mismatches and stale source fingerprints. These settings are reproducible quality profiles, not permission to replace missing frames with interpolation.
